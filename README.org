* Introduction

A small personal package that makes echo-area messages look nicer: each
message gets an icon and a color depending on whether it is an error, a
success or plain information.

I started it for a video about making Emacs look good, then decided to
share it.

* Connected links

- [[https://www.gnu.org/software/emacs/manual/html_node/elisp/Displaying-Messages.html][Displaying messages in the echo area]] (Emacs Lisp manual)

* Install

Requires Emacs 29.1 or newer.

** elpaca

#+begin_src emacs-lisp
(use-package pretty-message
  :ensure (:host github :repo "artawower/pretty-message.el")
  :config
  (pretty-message-mode 1))
#+end_src

** package-vc (built in)

#+begin_src emacs-lisp
(package-vc-install "https://github.com/artawower/pretty-message.el")
(require 'pretty-message)
(pretty-message-mode 1)
#+end_src

* Usage

Turn the mode on with =M-x pretty-message-mode=. Then
=(message "Hello")= shows as =❯❯ Hello=, =Wrote file= as =✓ Wrote file=,
and errors as =✗ …=.

Patterns, icons and faces can be changed with
=M-x customize-group RET pretty-message=:

- =pretty-message-error-regexps=, =pretty-message-success-regexps=: how messages are classified
- =pretty-message-error-prefix=, =pretty-message-success-prefix=, =pretty-message-info-prefix=: the icons
- faces =pretty-message-error=, =pretty-message-success=, =pretty-message-info= and their =-prefix= variants
